\section{Goal}
Use \texttt{numba.cuda} to get basic information about the GPU:
its name, number of multiprocessors, number of cores and memory size.

I ran the code on Google Colab (GPU runtime) because my laptop has no
NVIDIA GPU. The GPU is a \textbf{Tesla T4}.

\section{Method}
\begin{itemize}
  \item \textbf{Name and ID:} \texttt{cuda.select\_device(0)} gives a
  device object. I read \texttt{id}, \texttt{name} and
  \texttt{compute\_capability} from it.
  \item \textbf{Multiprocessors:} read from
  \texttt{MULTIPROCESSOR\_COUNT}.
  \item \textbf{Cores:} Numba does not give this number directly.
  Cores per SM depend on the compute capability, so I used a small
  lookup table:
  \begin{center}
    total cores = number of SMs $\times$ cores per SM
  \end{center}
  \item \textbf{Memory:} \texttt{cuda.current\_context().get\_memory\_info()}
  returns free and total memory in bytes.
\end{itemize}

\section{Code}
\begin{verbatim}
from numba import cuda

# compute capability -> cores per SM
CORES_PER_SM = {(6, 0): 64, (6, 1): 128, (7, 0): 64,
                (7, 5): 64, (8, 0): 64, (8, 6): 128}

device = cuda.select_device(0)
print("ID:", device.id)
print("Name:", device.name)

cc = tuple(device.compute_capability)
sm = device.MULTIPROCESSOR_COUNT
print("SM count:", sm)
print("Total cores:", sm * CORES_PER_SM[cc])

free, total = cuda.current_context().get_memory_info()
print("Total memory (MB):", total / 1024**2)
print("Free memory (MB):", free / 1024**2)
\end{verbatim}

\section{Conclusion}
The Tesla T4 has 40 SMs with 64 cores each, so 2560 cores in total,
and about 14.56 GB of memory. The number of cores is not given
directly by Numba; it must be calculated from the compute capability.
